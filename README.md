# Explorando o Universo — Homepage cinematográfica v0.2

Implementação React + TypeScript + Vite da referência visual aprovada.

## Executar

```bash
npm install
npm run dev
```

Execute os comandos na pasta extraída que contém o `package.json`. Com o Vite rodando, abra http://localhost:5173 no navegador. No PowerShell, use `npm.cmd` se a execução de `npm.ps1` estiver bloqueada. O `index.html` da pasta raiz precisa do Vite para carregar o código React. Para abrir no celular na mesma rede, use o IP local do computador e a porta 5173 (libere a porta no firewall se necessário).

## Recursos

- Home com composição de astronauta, cosmos, Terra e observatórios.
- Sete categorias navegáveis com miniaturas derivadas da referência visual.
- Seção Em Destaque com carrossel funcional.
- Busca de categorias, menu mobile, alternância de brilho e transição suave entre páginas.
- Preferência do sistema por movimento reduzido respeitada.

## Limitações

- A arte é uma ilustração conceitual, não uma representação astronômica cientificamente precisa.
- As imagens dos cartões foram recortadas da arte de referência, portanto ainda podem conter pequenos elementos tipográficos incorporados à imagem. Para produção, substituir por fotografias e renders licenciados individualmente.
